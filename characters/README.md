# Protagonistas

Biblia de personajes para EL PRIMER FECA.

Cada protagonista debe vivir en su propia carpeta y tener, como minimo:

- `profile.md` - identidad editorial, voz, look, rol y limites.
- `assets/` - referencias visuales, voces, renders, fondos y props propios.
- `scripts/` - monologos, pruebas de voz y segmentos escritos para ese personaje.
- `production-notes/` - notas de generacion, prompts aprobados, errores y decisiones.

## Regla De Oro

No mezclar identidad visual, tokens, sesiones, referencias privadas ni assets de otras cuentas.
`primerfeca` puede usar infraestructura generica, pero los personajes de EL PRIMER FECA tienen que ser propios.

- `co-conductor/` - contrapunto, remate, ritmo y conversacion.
- `movilero/` - calle, reacciones, escenas externas y notas absurdas con verdad adentro.
- `analista/` - contexto, tecnologia, politica, economia y lectura fina.
- `por-definir/` - personajes todavia sin nombre o rol cerrado.
- `_template/` - plantilla para crear nuevos protagonistas.

## Flujo

1. Crear o completar `profile.md`.
2. Guardar referencias propias en `assets/`.
3. Probar voz con textos cortos en `scripts/`.
4. Registrar prompts y resultados en `production-notes/`.
5. Solo pasar a publicacion cuando el personaje este aprobado por Santi.
